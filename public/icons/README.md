# PWA Icons

This folder needs the following PNG icons before publishing:

- icon-72.png (72x72)
- icon-96.png (96x96)
- icon-128.png (128x128)
- icon-144.png (144x144)
- icon-152.png (152x152)
- icon-192.png (192x192) — also used as maskable
- icon-384.png (384x384)
- icon-512.png (512x512) — also used as maskable

## Quick generation
Use https://realfavicongenerator.net/ or https://maskable.app/editor with a
single 1024x1024 source PNG and download the full set.

Until icons are added, the install prompt will still work but the home-screen icon will be blank.
